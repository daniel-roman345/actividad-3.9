# FitTracker - UI (Daniel salas roman)

Proyecto: Maquetación web (HTML5 + CSS3) del prototipo *FitTracker – Workout Management*.

## Estructura
- index.html
- styles/style.css
- assets/ (fonts, icons, images, videos)
- templates/

## Cómo ejecutar
1. Abrir `index.html` directamente en el navegador, o
2. Con Visual Studio Code: usar *Live Server* (Right-click → Open with Live Server)

## Notas
- Maquetación responsive usando CSS Grid/Flexbox.
- Uso de etiquetas semánticas: header, nav, main, section, article, aside, footer.
